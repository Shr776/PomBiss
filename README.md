## 🇮🇷 فارسی

### 📺 درباره پلاگین

**PomBiss** یک پلاگین حرفه‌ای برای رسیورهای Enigma2 است که فیدهای ورزشی زنده را از یک کانال تلگرام دریافت و نمایش می‌دهد. این پلاگین به‌طور خودکار کلیدهای BISS را در SoftCam.Key ذخیره می‌کند.

### ✨ ویژگی‌های اصلی

- ✅ دریافت خودکار فیدها از کانال تلگرام
- ✅ ذخیره خودکار کلید BISS در SoftCam.Key
- ✅ اسکن خودکار ماهواره و تنظیم فرکانس
- ✅ آپدیت خودکار پلاگین از GitHub
- ✅ سیستم ثبت‌نام با MAC Address
- ✅ پاک کردن کلیدهای قدیمی
- ✅ رابط کاربری زیبا

### 📋 پیش‌نیازها

- رسیور Enigma2
- اتصال اینترنت فعال
- Emulator نصب‌شده (OSCam-EMU, NCam, GCam)
- فایل SoftCam.Key
- wget و unzip

### 🚀 نصب از Telnet

بعد از اتصال با PuTTY یا DCC این دستور رو بزن:

wget -qO- https://raw.githubusercontent.com/Shr776/PomBiss/main/installer.sh | sh

بعد از نصب، رسیور خودکار ریستارت می‌شود.

### 🎯 نحوه فعال‌سازی

1. پلاگین را باز کن
2. صفحه ثبت‌نام ظاهر می‌شود
3. Username و Password و Country و Receiver و Age را وارد کن
4. GREEN: Register را بزن
5. صفحه Waiting for Approval ظاهر می‌شود
6. منتظر تایید ادمین باش
7. بعد از تایید، پلاگین خودکار باز می‌شود

### 🎮 نحوه استفاده

| دکمه | عملکرد |
|------|---------|
| OK / GREEN | اسکن فید |
| BLUE | پاک کردن کلیدها |
| YELLOW | آپدیت پلاگین |

## 🇬🇧 English

### 📺 About the Plugin

**PomBiss** is a professional plugin for Enigma2 receivers that fetches live sports feeds from a Telegram channel and automatically saves BISS keys to SoftCam.Key.

### ✨ Main Features

- ✅ Automatic feed fetching from Telegram
- ✅ Auto-save BISS keys to SoftCam.Key
- ✅ Automatic satellite scanning
- ✅ Auto-update from GitHub
- ✅ MAC Address registration
- ✅ Clear old keys
- ✅ Beautiful UI

### 📋 Requirements

- Enigma2 receiver
- Active internet connection
- Installed Emulator (OSCam-EMU, NCam, GCam)
- SoftCam.Key file
- wget and unzip

### 🚀 Installation via Telnet

After connecting with PuTTY or DCC, run:

wget -qO- https://raw.githubusercontent.com/Shr776/PomBiss/main/installer.sh | sh

After installation, the receiver will restart automatically.

### 🎯 Activation

1. Open the plugin
2. Registration page appears
3. Enter Username, Password, Country, Receiver, Age
4. Press GREEN: Register
5. Waiting for Approval screen opens
6. Wait for admin approval
7. After approval, plugin opens automatically

### 🎮 How to Use

| Button | Function |
|--------|----------|
| OK / GREEN | Scan feed |
| BLUE | Clear keys |
| YELLOW | Update plugin |
| RED | Exit |
